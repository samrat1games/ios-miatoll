Как установить.

Нужен компьютер, кабель и телефон с разблокированным загрузчиком. Android на этом разделе будет стёрт: сделайте копию.

  1. Разблокируйте загрузчик и сохраните разделыСохраните копии boot, modem, persist, modemst1/2 до любых изменений.
  2. Соберите образ iOSСкрипт берёт стандартный iPhone-образ и собирает корневой раздел для телефона.
    tools/mkiosroot-macos.sh
  3. Прошейте раздел userdataЭто заменяет Android. Телефон должен быть в режиме fastboot.
    fastboot flash userdata ios16-root.simg
  4. Прошейте ядро и загрузчик в bootОбраз собирает GitHub Actions из исходников XNU 8796.
    fastboot flash boot shim-boot.img
fastboot reboot
  5. Подождите минутуНа экране «Powered by iOS», затем экран блокировки. Нажмите кнопку громкости при включении, чтобы увидеть журнал загрузки.
Важно. Сборка не поставляется с файлами Apple. Образ iOS вы собираете на своём компьютере из официального IPSW. Проект независимый и не связан с Apple Inc.
