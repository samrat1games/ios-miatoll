# iOS Miatoll v0.1 (первая публичная сборка)

Настоящий iOS 16.7 (ядро XNU 8796) на **Redmi Note 9S (curtana, miatoll, SM6250)**. Без эмуляции.
Автор: Samrat. Идеи для слоя Wi-Fi в следующих версиях: HackiOS (OOSEX GANG).

## Что работает
- Загрузка с флеш-памяти телефона: логотип «Powered by iOS», внизу «By Samrat»; кнопка громкости при включении показывает журнал.
- Экран блокировки, рабочий стол, мультитач, кнопки, стандартные приложения Apple.
- MiatollTools: диагностика железа, тест экрана и тача, установка IPA по ссылке, ползунок яркости.
- Интернет через USB-кабель (при запуске через `fastboot boot`).

## Чего ещё нет
- **Wi-Fi** (в работе: модем запускается, канал связи с ним есть, драйвер чипа WCN3990 не готов), Bluetooth, камера, SIM, IMEI.
- Обои, размытие фона, системный ползунок яркости.
- Правильная дата на чужих телефонах: в образе смещение часов для телефона автора. На другом телефоне дату нужно откалибровать (см. `sweetnow` в `tools/mkadt.py` / NOTES.md).
- Модем в этой сборке выключен (`sweetmodem=0`), чтобы система была стабильной.

## Установка (кратко)
Нужны: Mac, разблокированный загрузчик, **свой IPSW iPhone X 16.7.16** (файлов Apple здесь нет).
1. Сделайте копии разделов `boot`, `modem`, `persist`, `modemst1/2`, `fsg`, `fsc`. **Android на `userdata` будет стёрт.**
2. Соберите корневой раздел iOS: `tools/mkiosroot-macos.sh`, затем `tools/img2simg.py`.
3. `fastboot flash userdata ios16-root.simg`
4. `fastboot flash boot ios-miatoll-boot-v0.1.img`, затем `fastboot reboot`.

Сумма SHA-256 образа загрузки: см. `SHA256SUMS.txt`.
